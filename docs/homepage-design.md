# 寻声首页设计与衔接

## 页面与视觉

首页 `/` 以简短产品介绍、唱片视觉和中下部的会话输入框构成；`/explore` 是原有音乐探索工作台。导航中的“进入探索”可继续最近对话；首页提交的新想法开启独立会话，跳转后的 `conversation` 参数只包含会话 ID，不包含用户输入。

视觉采用音乐杂志／唱片店方向：暖白 `#f8f7f4`、墨色 `#242320`、砖红 `#a64b3c`、灰褐细线；宋体标题与简洁系统无衬线控件。开放版式；首页与工作台共用输入框圆角 token：桌面 24px、小屏 20px。开始探索按钮采用胶囊轮廓，工作台发送按钮采用圆形，用户消息气泡桌面 20px、小屏 18px 圆角；无界面渐变或投影。输入框聚焦时以砖红边线提示。概念中的唱片摄影作为独立透明 WebP 素材使用，其封套上的 SOUNDSEEK 属于画面内容。

页面顺序：品牌与探索方式／关于寻声／账户／进入探索导航 → 两行大标题与产品介绍／唱片画面 → 会话输入与开始探索按钮 → 两个填入话题的快捷入口 → 三条简短能力说明 → 署名。首屏不新增角标、统计数字、推荐榜单或功能卡片网格。

参考画面布局：1448×1086；页边距约40px、内容最大宽1320px、主输入宽1040px。标题约84px，正文17–21px，控件14–19px。小屏将唱片移至介绍下方，输入保持可见且不横向溢出。

## 真实衔接

1. 提交前先读取 auth/session，建立访客与 CSRF Cookie。
2. 创建会话，将输入作为首条消息发送至既有 messages 接口。
3. API 接受消息后，进入 `/explore?conversation=...`；对话页选择这段会话，并沿用既有 AgentRun 事件恢复。
4. 消息提交失败时保留输入、已创建的会话 ID 和相同 Idempotency-Key。服务端接受消息后界面加载失败再重试也不会重复发送。

输入草稿保存在当前标签页 SessionStorage，禁止将消息放入 URL。输入为空或连接中不重复提交；Enter 发送，Shift+Enter 换行，中文输入法确认不发送。网络超时和服务不可用显示可读错误，并允许重试。

View Transition API 可用时，在首页与工作台之间对品牌和输入区域做约360ms的共享元素过渡；不可用时使用约360ms的轻微位移与淡出淡入兼容过渡。遵守 prefers-reduced-motion。工作台按需加载，并在输入框获得焦点时预加载。

## 验证边界

浏览器的接口夹具用于核验首页→会话、重试、消息只提交一次、刷新恢复和响应式布局；真实音乐推荐与第三方模型质量不由界面夹具证明。

## 顶栏导航与账户

探索方式提供“发现音乐、了解作品、探索偏好”三个引导，将可编辑话题填入首页输入框、滚动并聚焦；由用户主动提交。关于寻声跳转介绍区域；进入探索沿用工作台入口。不单独添加最近对话入口。

首页通过现有 auth/session 读取账户状态；登录入口复用工作台的共用原生 dialog，支持邮箱登录、注册和服务端已启用时的 GitHub 登录。登录成功留在首页，保留输入；登录后展示头像／称呼，展开后可管理账户及退出。身份通过 Cookie 和 CSRF 契约同步，不保存密码到浏览器存储。账户连接失败时显示提示并可重试，访客探索保持可用。

桌面保留轻量文字导航和单个胶囊主入口；850px 以下次要导航折叠到菜单。弹层支持 Escape、点击外部关闭与键盘焦点恢复；登录窗口使用原生模态 dialog 限制焦点范围。

页内锚点由浏览器处理，不触发工作台页面过渡或重置滚动位置；仅在首页／工作台或会话 ID 变化时处理路由恢复。

## 声音驱动的黑胶试听

推荐歌曲首次试听后在同张推荐卡内展开黑胶播放器，使用真实 listening-options 试听地址。支持暂停／继续、进度调整、切歌与播放结束；所有推荐卡共享播放所有权，切换卡片停止上一段音频。唱片 SVG 和频谱 Canvas 为原生绘制，无新增运行时依赖。唱片启停有惯性，切歌文字淡入；有封面时作为中心标签，无封面时使用砖红标签。

频谱来自 Web Audio AnalyserNode 的实时频率数据；跨域匿名加载失败时仅尝试一次普通播放降级，显示“频谱暂不可用”，不以模拟频谱冒充声音数据。无 Web Audio 时仍可普通播放。未知时长显示占位；源提供可用时长后支持进度调整。系统减少动态效果或页面隐藏时停止视觉动画，退出会话时清理音频节点和 AudioContext。

本机接口夹具用于交互验收，包含真实音频测试信号、无 CORS 许可的跨源资源，以及一个真实 Apple 试听地址；Apple 样本抽查不能证明所有地区与曲目均可试听。

## 账户菜单与设置

点击已登录头像先展开贴靠入口的小型账户菜单：账户摘要、设置、音乐偏好与记忆、退出登录。设置进入同一浮层内的分类列表，再进入具体配置；返回按钮和 Escape 逐级返回。没有全屏遮罩，不锁定页面滚动，不改变 URL；点击外部关闭。工作台入口位于左下角，菜单从头像上方展开并左对齐，首页复用顶栏账户入口；未登录仍打开原登录窗口。

称呼使用 PATCH /api/v1/auth/profile 保存到账户，仅允许当前已登录用户修改自己的显示名称。音乐记忆使用现有查询／移除接口，移除前在菜单内确认，原始对话不受影响。播放音量、频谱开关、减少动态效果保存在当前浏览器（soundseek-playback-settings-v1），即时应用于播放器；未开启减少动态效果时仍遵循系统设置。
