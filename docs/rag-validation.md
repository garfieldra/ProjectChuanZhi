## 边界

接口验收使用自行生成的合成测试材料，只证明功能链路，不能作为真实音乐事实入库。没有将这些材料写入原项目业务数据库。

隔离环境未配置真实 LLM API Key；模型辅助提取无 Key 时返回需人工整理，Agent 的事实引用与语义审校接入使用可控模型替身测试。此记录不声称已验证真实 Provider 的长篇音乐分析质量。

真实资料需要维护者导入、确认实体和审核发布，随后建立带黄金知识 ID 的开发集与独立验收集。Recall@10、引用支持率、无答案处理和实际部署 P95 需要在该语料上测量，不能用合成接口验收替代。

向量最低相似度默认 0.5，是可配置的初始召回参数，不是事实置信度，也未宣称已通过真实语料标定。低相似度命中会被排除，其他候选仍需权威检查与语义判断。
